# Regras de segurança do repositório LidIA

Este repositório contém o app promocional em produção, usado ativamente por uma campanha paga do Google Ads. O link da campanha aponta direto para https://aid-negocios.github.io/LidIA/ (o index.html da raiz).

REGRAS OBRIGATÓRIAS PARA QUALQUER SESSÃO DO CLAUDE:

1. Nunca faça commit direto na branch "main". Trabalhe sempre em uma branch nova.
2. Nunca altere o arquivo index.html da raiz, nem nada dentro da pasta "teste/", a menos que o Neto peça isso explicitamente e com clareza.
3. Ao terminar uma tarefa, abra um Pull Request da sua branch para "main" e PARE. Nunca faça merge sozinho, mesmo que pareça óbvio ou seguro. O merge é sempre manual, feito pelo Neto depois de revisar.
4. Se não tiver certeza se uma mudança é segura, pergunte antes de agir.
